# TechWorld — Branded E-commerce Frontend Demo

A responsive electronics storefront with a premium dark navy/tech-blue design, brand browsing, category filters, search, sorting, product cards, wishlist, cart quantity controls, and a simulated checkout.

## Run locally
Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Included
- Popular brand sections: Apple, Samsung, OnePlus, Sony, boAt, Logitech, ASUS and Dell
- Product search, category/brand filters and price sorting
- Wishlist and cart interactions
- Demo checkout only; no real payment is processed
- Locally bundled illustrative product images in `assets/`

## Important
This is a frontend demo, not an official retailer or an authenticated brand store. Brand names are shown for categorisation; product images and prices are illustrative and may not represent exact manufacturer models. No real payments or orders occur.
